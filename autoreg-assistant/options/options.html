Добавить свой провайдер (JSON)

Опишите API временной почты. Плейсхолдеры {{token}}, {{apiKey}}, {{email}}. Пути ответа — через точку (data.messages.0.id). Ключ API можно указать прямо в поле apiKey конфига.
